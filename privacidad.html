Política de privacidad

Vigente desde el 5 de septiembre de 2026.

Qué datos toca

Solo los de la propia cuenta conectada — la del canal @tuluzbaja — y nada de ninguna otra persona:

Perfil básico
Identificador, nombre visible y foto de perfil de la cuenta conectada — lo mínimo para confirmar que la API está hablando con la cuenta correcta.
Vídeo
El archivo, título, descripción y etiquetas que el operador del canal aporta para cada publicación.

Dónde vive ese dato

El token de autorización se guarda cifrado por permisos de sistema, en el ordenador del propio operador — nunca en un servidor de terceros ni en una nube compartida. No sale de ahí salvo para hablar directamente con la API oficial de cada plataforma.

Qué no se hace con los datos

  • No se usan con fines publicitarios ni de perfilado.
  • No se venden ni se comparten con ningún tercero.
  • No se conservan más allá de lo necesario para completar cada publicación.

Revocar el acceso

El operador puede retirar el permiso en cualquier momento desde la configuración de desarrollador de cada plataforma. Al revocarlo, el token guardado localmente deja de funcionar y se borra.

Contacto: a través de las cuentas oficiales del canal — @tuluzbaja en Instagram, TikTok, YouTube o Facebook.
